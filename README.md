# UPT — University Poker Tour 公式サイト

大学生限定の大学対抗ポーカートーナメント「UPT」の公式サイトです。

- 公開URL：https://upt-project.github.io/upt.site/
- 公開方法：GitHub Pages（`main` ブランチから公開）
- 構成：`index.html` 1ファイル中心の静的サイト（CSS・JS内蔵）
  - `index.html` — トップページ
  - `players-guide.html` — プレイヤーズガイド
  - 画像：`tournament*_*.jpeg/png`（大会写真・フライヤー）、`sponsor_*.jpg/jpeg`（協賛ロゴ）

## 公開の仕組み（GitHub連携）

1. このリポジトリ（`upt-project/upt.site`）の `main` ブランチに push する
2. GitHub Pages が自動で再公開する（通常1分ほど）
3. https://upt-project.github.io/upt.site/ を開いて確認する

特別なビルドやデプロイ作業はありません。HTMLを書き換えて push するだけです。
ローカルでの確認は次のコマンドでできます。

```bash
cd upt.site
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## 次回大会が決まったときの更新手順（4か所だけ）

次回大会が決まったら、`index.html` の次の4か所を書き換えます。
詳しい場所と文面例は、ファイル内の `<!-- 更新メモ -->` コメントにも書いてあります。

| # | 場所 | やること |
|---|------|---------|
| 1 | ヒーローの `hero-next-card` | 「次回大会は調整中」→ 第○回・日時・会場に書き換える |
| 2 | エントリー `#entry` | 「申込フォームは大会の決定後に公開」→ 個人・団体の申込フォームURLに差し替える（旧フォームのURLはHTMLコメントに残してあります） |
| 3 | 大会詳細 `#tournament` | 「第5回の記録です」→ 次回の種目・料金・タイムテーブル・プライズに書き換える |
| 4 | フッター | 「最終更新：2026年11月23日」→ 更新日に書き換える |

あわせて、ナビと追従ボタンの文言（現在は「次回大会をチェック」）を
「参加申し込み」に戻すかどうかも確認してください。

## 大会が終わったときの更新手順

1. ヒーローとエントリーを「次回大会は調整中」に戻す（上の手順1・2の逆）
2. アーカイブ `#archive` の開催履歴に1枚カードを追加する
3. `<script>` 内の `events` オブジェクトにも同じ回を追加する
   （写真ファイルがあれば `tournamentN_*.jpeg` として追加し、`photos` に指定する）
4. 参加大学・実績の数字が変わった場合は、ヒーロー下の stats と
   「大会の魅力」セクションの数字もあわせて直す
